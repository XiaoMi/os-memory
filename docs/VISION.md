## 中文

### OS-Memory：面向操作系统的用户全生命周期记忆系统

OS-Memory 是面向操作系统场景的用户全生命周期前沿记忆系统，致力于构建 OS 原生的统一记忆底座，让系统具备持续理解用户、沉淀经验、演化认知的能力。

### 核心特性

- **统一记忆抽取**：从行为日志、交互事件、文件内容、上下文状态等异构数据中提炼结构化记忆。
- **分层记忆存储**：支持时序记忆、语义记忆、情景记忆等多类型记忆持久化。
- **全生命周期管理**：提供检索、更新、衰减、冲突消解与权限控制能力。
- **持续自进化**：通过持续交互让记忆关联补全、偏好演进与知识更新同步发生。

### 项目愿景

OS-Memory 希望探索操作系统级记忆系统的技术标准与落地路径，覆盖桌面、移动、嵌入式等多形态 OS 场景，让操作系统从“执行工具”演进为“长期认知载体”。

### 路线图

- 定义记忆对象模型与生命周期语义
- 设计 OS 数据源接入适配层
- 探索时序、语义、情景记忆的存储策略
- 建立隐私、权限、保留与审计机制
- 原型化提取与检索流程
- 建立记忆质量与安全性评估方法

## English

### OS-Memory: A User Lifecycle Memory System for Operating Systems

OS-Memory is a frontier memory system for operating system scenarios. It aims to build an OS-native unified memory foundation that helps the system continuously understand users, accumulate experience, and evolve its cognition over time.

### Key Features

- **Unified Memory Extraction**: Extract structured memories from heterogeneous sources such as behavioral logs, interaction events, file content, and contextual state.
- **Layered Memory Storage**: Persist temporal, semantic, and episodic memory types with clear lifecycle boundaries.
- **Full Lifecycle Management**: Support retrieval, update, decay, conflict resolution, and access control.
- **Continuous Self-Evolution**: Let memory improve through ongoing interaction, including association completion, preference evolution, and knowledge refresh.

### Vision

OS-Memory explores the technical direction and practical path for OS-level memory systems across desktop, mobile, and embedded environments, helping operating systems evolve from execution tools into long-term cognitive carriers.

### Roadmap

- Define the memory object model and lifecycle semantics
- Design adapters for OS data sources
- Explore storage strategies for temporal, semantic, and episodic memory
- Establish privacy, permission, retention, and audit mechanisms
- Prototype extraction and retrieval pipelines
- Build evaluation methods for memory quality and safety
